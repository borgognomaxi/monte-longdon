# Monte Longdon

Juego en primera persona sobre la batalla de Monte Longdon, Islas Malvinas, junio de 1982.
Los personajes son inventados; la batalla ocurrió de verdad.

## Qué hay

- **Misión 1: Primera Noche** (8 de junio): conocés al pelotón, probás el fusil y hacés tu primera guardia.
- **Misión 3: La noche del 11** (prototipo de combate): defendés tu pozo en oleadas y te replegás a la cresta.

## Cómo jugar

Abrí `index.html` en el navegador de una computadora (no necesita instalar nada).

Mouse para mirar · W A S D caminar · Shift correr · C agacharse · Clic disparar · R recargar · F bengala · E hablar o tomar munición · Esc pausa

## Hecho con

- [Three.js](https://threejs.org/) para el 3D
- Sonidos fabricados con la Web Audio API
